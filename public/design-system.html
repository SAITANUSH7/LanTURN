LanTURN Design system

Studio design system

Calm, precise and fast to scan. Neutral surfaces, one brand accent, and colour only where it carries meaning.

Principles

Neutral first

Graphite surfaces with hairline borders. No glass, glow or decorative gradients.

Colour means something

Green, amber and red are for scores and status. Section hues mark where you are.

Readable by default

16px body, 1.6 line height, 44px touch targets, visible focus, both themes.

Section colours

Each destination owns a hue. It appears on the sidebar icon, the page marker, focus rings and the primary button.

Type

Heading one, 36px, tight tracking

Heading two for sections

Heading three for card titles

Body text is Inter at 16px with a 1.6 line height. Keep line length under about 70 characters.

Secondary text uses the muted token and still passes contrast.

Numbers and code use JetBrains Mono.
